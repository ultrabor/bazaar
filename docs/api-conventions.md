# Params of get list 

    page  int  
    limit int // max is 100

## Product filters

`GET /product` принимает необязательные query-параметры:

- `name` — регистронезависимый поиск буквальной подстроки. Символы `%`, `_` и `\` не считаются шаблонами.
- `sku` — точное совпадение SKU.
- `unit` — точное совпадение: `kg`, `meter`, `piece` или `liter`.
- `category_id` — точное совпадение UUID категории. Фильтр продолжает работать после архивирования категории.

Несколько фильтров объединяются через `AND` и работают вместе с `page` и `limit`.
Если совпадений нет, API возвращает `200` и `[]`.

## Product category

- `category_id` в `POST /product` необязателен.
- Назначить можно только активную категорию своей компании.
- В `PUT /product/{id}` отсутствие `category_id` или значение `null` снимает категорию.
- Передача прежнего `category_id` сохраняет связь, даже если категория уже архивирована.
- Архивирование категории не архивирует товары, не скрывает их и не удаляет `category_id`.
- Архивную категорию нельзя назначить новому товару или вместо другой категории.

## Categories

`GET /category` возвращает только активные категории с общей пагинацией `page`/`limit`.
Пустой результат возвращается как `200` и `[]`.
Название обязательно и уникально без учёта регистра среди активных категорий одной компании.
После архивирования название можно использовать повторно.

## without it will be return 
    page = 1
    limit = 20

| Ситуация | Статус | Код ошибки |
|---|---:|---|
| Неправильный JSON | 400 | `invalid_json` |
| Неправильные поля или единица | 400 | `validation_error` |
| Неправильная пагинация | 400 | `invalid_pagination` |
| Неправильный формат UUID товара | 400 | `invalid_product_id` |
| Неправильный формат UUID категории | 400 | `invalid_category_id` |
| Пустое название категории | 400 | `validation_error` |
| Товар недоступен или отсутствует | 404 | `product_not_found` |
| Категория отсутствует, архивирована или принадлежит другой компании | 404 | `category_not_found` |
| Дубликат SKU | 409 | `sku_conflict` |
| Дубликат активного названия категории | 409 | `category_name_conflict` |
| Неожиданная внутренняя ошибка | 500 | `internal_error` |
| Таймаут зависимости | 503 | `service_unavailable` |

# Error format
```json
{
  "error": {
    "code": "invalid_pagination",
    "message": "limit must be between 1 and 100"
  }
}
```
